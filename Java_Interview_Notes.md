## 41. What is Runtime Polymorphism or Dynamic Method Dispatch?

The method declaration gets bound to its definition at runtime by the JVM based on the object created. This is called **runtime polymorphism**.

## 42. What is Dynamic Binding and Late Binding?

Since the method declaration gets bound to its definition, it is called **dynamic binding**.

Since the method declaration gets bound to its definition at runtime, it is called **late binding**.

## 43. What is Abstraction?

Hiding the complexity of the system and exposing only the required functionality to the end user is called **abstraction**.

## 44. What is an Abstract Class?

Any class which is declared with the keyword `abstract` is called an **abstract class**.

## 45. When are Abstract Methods Used?

Any method which is declared with the keyword `abstract` is called an **abstract method**.

## 46. What is Encapsulation?

Encapsulation is one of the OOPs principles. Java is by default encapsulated.

## 47. What is the Primary Benefit of Encapsulation?

The main benefit of encapsulation is the ability to modify our implemented code without breaking the code of others who use our code.

Encapsulation gives maintainability, flexibility, and extensibility to our code.

## 48. What is an Interface?

An interface is by default abstract and it is a pure abstract body.

## 49. Give Some Features of Interface

Some features of an interface include:

* An interface cannot be instantiated.
* An interface does not contain any constructors.
* All of the methods in an interface are abstract.

## 50. Define Packages in Java

A package is a folder structure which is used to store similar kinds of files.

The packages should be created in reverse order.
